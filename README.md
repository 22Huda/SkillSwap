SkillSwap 🎓
Overview
SkillSwap is a web-based student skill exchange platform designed to help university students share their academic skills and request assistance from other students.
Problem
University students may need academic support or have skills they can share, but there is no structured platform that connects students based on their skills.
Proposed Solution
SkillSwap provides a platform where students can:
Create profiles
List their skills
Browse available skills
Request help
Communicate with other students
Manage their profiles
Target Users
University students within the same university who want to share skills or request academic support.
Project Features
User Registration and Login
Skill Browsing
Skill Requests
Messaging
Profile Management
Project Process
The project followed the software development lifecycle:
Problem Definition
System Requirements
System Design
Prototyping
Testing and Evaluation
Prototype
The prototype demonstrates the main user journey, including registration, skill browsing, skill requests, messaging, and profile management.
